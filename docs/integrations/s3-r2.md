# S3 and Cloudflare R2 (file storage, live)

Adapter: `apps/api/src/momentsales/adapters/storage/s3.py`. Local development uses `adapters/storage/local.py`. Selected by `STORAGE_BACKEND=s3`.

Checked against the official docs on 2026-11-07:
- https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html
- https://docs.aws.amazon.com/AmazonS3/latest/userguide/default-encryption-faq.html
- https://docs.aws.amazon.com/AmazonS3/latest/userguide/ShareObjectPreSignedURL.html
- https://developers.cloudflare.com/r2/api/s3/api/
- https://developers.cloudflare.com/r2/api/s3/presigned-urls/
- https://developers.cloudflare.com/r2/reference/data-security/

| Item | S3 | R2 |
| --- | --- | --- |
| Never overwrite | `PutObject` with `If-None-Match: *` → 412 if the key exists | Supported, 412 `PreconditionFailed` |
| Encryption at rest | SSE-S3 on every new object by default (can't be disabled) | Automatic AES-256; `x-amz-server-side-encryption` **not implemented**, so we never send it |
| Presigned GET | Supported; SDK maximum not stated (CLI 7 days) | 1 s – 7 days; S3 API domain only, not custom domains |
| Endpoint / region | default AWS endpoint, `AWS_REGION` | `S3_ENDPOINT_URL=https://<ACCOUNT_ID>.r2.cloudflarestorage.com`, `AWS_REGION=auto` |

We sign URLs for 5 minutes (`SIGNED_URL_TTL_SECONDS=300`).

Not used: `response-content-disposition` on presigned URLs (not confirmed on the pages read), so downloads are named by the object key; the app shows the original filename.
